# Confidencialidad — D&D Servicios Integrales de Limpieza

**Clasificación: Experiencia real**

## Criterio general

Por tratarse de una organización real, toda la documentación relacionada con D&D publicada en este repositorio ha sido anonimizada y/o generalizada.

## Qué no se incluye en este repositorio

- Datos personales de empleados o terceros.
- Nombres completos de empleados.
- Números de teléfono o correos electrónicos privados.
- Credenciales o contraseñas.
- Configuraciones internas de sistemas.
- Información comercial sensible (contratos, tarifas, clientes específicos).
- Información propietaria de la organización.
- Cualquier dato que pudiera comprometer la seguridad de D&D o facilitar un ataque contra la organización.

## Marca de anonimización

Cuando corresponde, el contenido publicado utiliza la marca `[Información anonimizada por confidencialidad]` para indicar que se omitió o generalizó un dato específico.

## Autorización

La documentación publicada en esta sección refleja el trabajo realizado con el consentimiento de la organización para su uso como referencia de portafolio profesional, manteniendo el resguardo descrito anteriormente.
