# 05 — Seguridad de la Información

## Propósito

Esta sección desarrolla, de forma educativa y práctica, los principales dominios operativos de la seguridad de la información. El contenido es genérico y **no representa políticas oficiales de ninguna empresa específica**; sirve como referencia conceptual y como base para adaptar controles a distintos contextos organizacionales.
