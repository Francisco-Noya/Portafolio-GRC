# Continuidad — Plantillas

Plantillas genéricas para el desarrollo de un Business Impact Analysis (BIA) y de un esquema base de Business Continuity Plan (BCP) / Disaster Recovery Plan (DRP), tomando como referencia ISO 22301.

## Archivos

- `bia.csv` — Estructura para registrar procesos críticos, dependencias, RTO y RPO.
- `bcp-drp.md` — Esquema base de un plan de continuidad y recuperación ante desastres.

## Uso

1. Completar el BIA identificando procesos críticos, su impacto ante interrupción y sus tiempos objetivo de recuperación (RTO/RPO).
2. Utilizar el esquema de BCP/DRP como estructura para documentar estrategias de continuidad y recuperación.

Este contenido es genérico y con fines de referencia metodológica.
