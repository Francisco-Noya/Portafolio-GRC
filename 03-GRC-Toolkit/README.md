# 03 — GRC Toolkit

## Propósito

Esta sección reúne herramientas y plantillas **genéricas y reutilizables** para gestión de riesgos, controles, compliance y continuidad operativa. Están diseñadas para adaptarse a cualquier organización y no representan entregables específicos de ningún cliente, salvo que se indique expresamente lo contrario.

## Contenido

| Carpeta | Herramientas |
|---|---|
| [01-Gestion-de-Riesgos](./01-Gestion-de-Riesgos/) | Registro de riesgos, matriz de riesgos. |
| [02-Controles](./02-Controles/) | Catálogo de controles y control assessment. |
| [03-Gap-Assessment](./03-Gap-Assessment/) | Gap assessment ISO/IEC 27001. |
| [04-Continuidad](./04-Continuidad/) | BIA, BCP, DRP. |
| [05-Politicas](./05-Politicas/) | Plantilla de política de seguridad. |
| [06-Compliance](./06-Compliance/) | Checklist ISO/IEC 27001, checklist de proveedores. |
| [07-Activos](./07-Activos/) | Inventario de activos. |
| [08-Incidentes](./08-Incidentes/) | Registro de incidentes. |

## Uso

Cada plantilla incluye instrucciones básicas de uso en su propio README. Los archivos `.csv` pueden abrirse en cualquier hoja de cálculo (Excel, Google Sheets, LibreOffice Calc) para su adaptación.

## Aclaración

Estas herramientas son genéricas y fueron desarrolladas con fines de portafolio y estudio. No deben presentarse como entregables producidos para un cliente específico salvo que así se indique explícitamente en el documento correspondiente.
