# 03 — GRC Toolkit

## Propósito

Esta sección reúne herramientas y plantillas **genéricas y reutilizables** para la gestión de riesgos, controles, compliance, activos y continuidad operativa.

Los recursos están diseñados para adaptarse a diferentes organizaciones y escenarios de trabajo. No representan entregables específicos de ningún cliente, salvo que se indique expresamente lo contrario en el documento correspondiente.

## Uso

Cada herramienta incluye instrucciones básicas de uso en su propio README cuando corresponde.

Los archivos en formatos editables, como `.csv`, pueden abrirse y adaptarse utilizando herramientas de hoja de cálculo como Excel, Google Sheets o LibreOffice Calc.

Las plantillas están diseñadas como **puntos de partida** y deben adaptarse al contexto, alcance, riesgos y necesidades de cada organización antes de utilizarse en un entorno profesional.

## Naturaleza de las herramientas

Los recursos de esta sección fueron desarrollados como parte del **portafolio profesional y proceso de formación práctica en GRC**.

Su objetivo es demostrar la capacidad para estructurar herramientas aplicables a actividades como:

- Gestión de riesgos.
- Identificación y evaluación de controles.
- Gap assessments.
- Gestión de activos.
- Continuidad operativa.
- Desarrollo de políticas.
- Evaluaciones de compliance.
- Gestión y seguimiento de incidentes.

Las herramientas no constituyen, por sí mismas, evidencia de una implementación de controles, certificación, auditoría o evaluación formal de una organización.

## Aclaración

Estas herramientas son **genéricas, reutilizables y adaptables**.

No deben presentarse como entregables producidos para un cliente específico ni como evidencia de trabajo realizado para una organización determinada, salvo que el documento correspondiente indique expresamente esa relación.

Cuando una herramienta se derive o adapte de un trabajo realizado en una organización, deberá presentarse en su correspondiente sección de **Experiencia Real** o **Casos de Estudio**, según la naturaleza del proyecto.
