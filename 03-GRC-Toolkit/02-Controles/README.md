# Controles — Plantillas

Catálogo genérico de controles y plantilla de control assessment, basados en la estructura de dominios de ISO/IEC 27002:2022.

## Archivos

- `catalogo-controles.csv` — Selección ilustrativa de controles organizados por dominio (organizacionales, de personas, físicos, tecnológicos).

## Uso

El catálogo puede utilizarse como punto de partida para un ejercicio de control assessment: para cada control, registrar su estado de implementación (No implementado / Parcial / Implementado), evidencia disponible y observaciones.

Este contenido es genérico, con fines de referencia y estudio.
