# Controles — Plantillas

Catálogo genérico de controles y plantilla de evaluación de controles, tomando como referencia la estructura y los dominios de **ISO/IEC 27002:2022**.

## Archivos

- [**catalogo-controles.csv**](./catalogo-controles.csv) — Selección ilustrativa de controles organizados por categorías: organizacionales, de personas, físicos y tecnológicos.

## Uso

El catálogo puede utilizarse como punto de partida para un ejercicio de **control assessment**.

Para cada control, se puede registrar:

- Estado de implementación.
- Evidencia disponible.
- Observaciones.
- Brechas identificadas.
- Acciones de mejora.

Como referencia, el estado de implementación puede clasificarse como:

- **No implementado**
- **Parcialmente implementado**
- **Implementado**

La clasificación debe adaptarse al criterio de evaluación definido para cada organización.

## Consideraciones

La estructura y los controles utilizados como referencia deben interpretarse dentro del contexto de **ISO/IEC 27002:2022** y no sustituyen una evaluación formal de controles ni una auditoría.

El catálogo constituye una **selección ilustrativa y simplificada** para fines de estudio y portafolio.

## Naturaleza de la herramienta

Este contenido es **genérico y reutilizable**, y fue desarrollado con fines de referencia, formación práctica y demostración de capacidades en GRC.

No corresponde a ninguna organización específica ni representa evidencia de una evaluación formal de controles realizada para un cliente.
