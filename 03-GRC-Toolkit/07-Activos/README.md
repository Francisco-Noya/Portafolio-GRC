# Activos — Plantillas

Plantilla genérica para el **inventario y clasificación de activos** relevantes para la seguridad de la información y la gestión de riesgos.

## Archivo

- [**inventario-de-activos.csv**](./inventario-de-activos.csv) — Registro estructurado de activos de información, tecnológicos, físicos, servicios y otros recursos relevantes para la organización.

## Uso

Completar un registro por cada activo relevante, indicando, según corresponda:

- Identificador del activo.
- Nombre o descripción.
- Categoría.
- Propietario o responsable.
- Ubicación o entorno.
- Criticidad.
- Información asociada.
- Dependencias relevantes.
- Observaciones.

La información registrada debe adaptarse al **contexto, alcance y necesidades de cada organización**.

## Consideraciones

El inventario debe mantenerse actualizado y puede utilizarse como insumo para actividades de:

- Gestión de riesgos.
- Clasificación de información.
- Evaluación de controles.
- Continuidad operativa.
- Gestión de accesos.
- Identificación de dependencias.

La criticidad de cada activo debe determinarse utilizando criterios definidos por la organización y considerando su impacto sobre la **confidencialidad, integridad y disponibilidad**, cuando corresponda.

## Naturaleza de la herramienta

Esta plantilla es **genérica y reutilizable**, y fue desarrollada con fines de formación práctica, referencia y demostración de capacidades en GRC y gestión de activos.

No corresponde a ninguna organización específica ni representa un inventario real de activos de un cliente.
