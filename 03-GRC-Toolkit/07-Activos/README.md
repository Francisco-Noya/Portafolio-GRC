# Activos — Plantillas

Plantilla genérica de inventario de activos de información, base para cualquier ejercicio de evaluación de riesgos.

## Archivo

- `inventario-de-activos.csv`

## Uso

Completar un registro por cada activo relevante (información, hardware, software, servicios, personas), indicando su propietario y su nivel de criticidad para la organización.
