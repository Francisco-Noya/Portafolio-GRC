# Gap Assessment — Plantilla

Plantilla genérica para evaluar el nivel de cumplimiento de una organización respecto a los controles de ISO/IEC 27001 (Anexo A), como paso previo a la definición de un plan de mejora.

## Archivo

- `gap-assessment-iso27001.csv` — Estructura de evaluación por control (cumplimiento, brecha identificada, prioridad de cierre).

## Uso

1. Recorrer los dominios de control del Anexo A de ISO/IEC 27001.
2. Registrar el nivel de cumplimiento observado para cada control.
3. Documentar la brecha identificada y su prioridad de cierre.
4. Utilizar el resultado como insumo para un plan de tratamiento de riesgos y controles.

Esta plantilla es genérica y no refleja el resultado de una evaluación real.
