# Gap Assessment — Plantilla

Plantilla genérica para evaluar el estado de implementación de controles de seguridad de la información tomando como referencia **ISO/IEC 27001:2022**, como insumo para la identificación de brechas y la definición de acciones de mejora.

## Archivo

- [**gap-assessment-iso27001.csv**](./gap-assessment-iso27001.csv) — Estructura de evaluación por control, incluyendo estado de implementación, brecha identificada y prioridad de tratamiento.

## Uso

1. Revisar los controles aplicables al alcance definido para la organización.
2. Registrar el estado de implementación observado para cada control.
3. Documentar la brecha identificada y las observaciones relevantes.
4. Asignar una prioridad de tratamiento de acuerdo con los criterios definidos.
5. Utilizar los resultados como insumo para la definición de acciones de mejora, tratamiento de riesgos y fortalecimiento de controles.

## Consideraciones

Un **gap assessment** permite identificar diferencias entre un estado actual y un estado de referencia definido. No constituye por sí mismo una auditoría de certificación ni determina el cumplimiento formal de ISO/IEC 27001.

La aplicabilidad de los controles debe analizarse considerando el **alcance, contexto, riesgos y criterios definidos por cada organización**.

## Naturaleza de la herramienta

Esta plantilla es **genérica y reutilizable**, y fue desarrollada con fines de formación práctica, referencia y demostración de capacidades en GRC.

No corresponde a ninguna organización específica ni representa el resultado de una evaluación real.
