# Incidentes — Plantillas

Plantilla genérica de registro de incidentes de seguridad de la información.

## Archivo

- `registro-de-incidentes.csv`

## Uso

Registrar cada incidente detectado, su clasificación, impacto, acciones tomadas y estado de resolución. Sirve como insumo para el análisis de tendencias y la mejora continua del programa de seguridad.
