# Compliance — Plantillas

Checklists genéricos de apoyo para autoevaluación de cumplimiento frente a ISO/IEC 27001 y para evaluación de proveedores.

## Archivos

- `checklist-iso27001.csv`
- `checklist-proveedores.csv`

## Uso

Utilizar como lista de verificación de alto nivel; no reemplaza una auditoría formal de certificación.
