# Compliance — Plantillas

Checklists genéricos de apoyo para la **autoevaluación y revisión estructurada** de requisitos y controles relacionados con ISO/IEC 27001, así como para la evaluación de aspectos de seguridad y gestión de proveedores.

## Archivos

- [**checklist-iso27001.csv**](./checklist-iso27001.csv) — Lista de verificación de referencia para revisar requisitos y controles relacionados con ISO/IEC 27001.

- [**checklist-proveedores.csv**](./checklist-proveedores.csv) — Lista de verificación de referencia para evaluar aspectos de seguridad y gestión de proveedores.

## Uso

Estas herramientas pueden utilizarse como punto de partida para:

1. Revisar requisitos o controles aplicables.
2. Registrar el estado o resultado de la revisión.
3. Documentar observaciones y brechas identificadas.
4. Identificar acciones de mejora o seguimiento.
5. Mantener trazabilidad de las revisiones realizadas.

Los criterios de evaluación deben adaptarse al **contexto, alcance, riesgos y requisitos aplicables** de cada organización.

## Consideraciones

Los checklists constituyen herramientas de **apoyo y referencia** y no sustituyen una auditoría formal, una evaluación de certificación ni una determinación jurídica de cumplimiento.

La aplicabilidad de requisitos y controles debe analizarse de acuerdo con el alcance y contexto específico de cada organización.

## Naturaleza de las herramientas

Estas herramientas son **genéricas y reutilizables**, y fueron desarrolladas con fines de formación práctica, referencia y demostración de capacidades en GRC y compliance.

No corresponden a ninguna organización específica ni representan el resultado de una evaluación real de cumplimiento o de proveedores.
