# 02 — Casos de Estudio

## Propósito de la sección

Esta sección reúne proyectos académicos, ejercicios prácticos y proyectos de portafolio desarrollados para demostrar la aplicación de marcos de GRC y seguridad de la información. Es **completamente independiente** de la sección [01-Experiencia-Real](../01-Experiencia-Real/): ningún contenido de esta sección corresponde a trabajo remunerado ni a un proyecto solicitado formalmente por una organización.

## Qué incluye esta sección

- Proyectos académicos.
- Ejercicios prácticos de aplicación de marcos.
- Simulaciones y casos hipotéticos.
- Proyectos de portafolio basados en información pública y supuestos declarados.

## Qué no incluye esta sección

- Experiencias laborales reales (ver [01-Experiencia-Real](../01-Experiencia-Real/)).
- Auditorías oficiales o trabajos realizados con autorización formal de terceros.

| Caso | Clasificación |

| [02-Clinica-Santa-Maria](./02-Clinica-Santa-Maria/) | Proyecto académico / ejercicio práctico, organización ficticia. |
| [03-Continuidad-y-Resiliencia](./03-Continuidad-y-Resiliencia/) | Caso académico / práctico sobre continuidad de negocio. |

Cada caso especifica de forma explícita su naturaleza, sus supuestos y sus limitaciones metodológicas.
