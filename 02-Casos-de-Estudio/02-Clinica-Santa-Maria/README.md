# Clínica Santa María — Implementación Conceptual de SGSI

**Clasificación: Proyecto académico / ejercicio práctico**

## Naturaleza del proyecto

Clínica Santa María es una **organización ficticia**, utilizada exclusivamente para practicar conceptos de ISO/IEC 27001 y la construcción de un Sistema de Gestión de Seguridad de la Información (SGSI). Este caso **no representa experiencia laboral real** ni un proyecto realizado para una organización existente.

## Objetivo del ejercicio

Demostrar, sobre un escenario controlado del sector salud, la aplicación práctica de:

- Principios de un SGSI bajo ISO/IEC 27001.
- El modelo de Confidencialidad, Integridad y Disponibilidad (CIA).
- Identificación de activos, amenazas y vulnerabilidades.
- Evaluación y tratamiento de riesgos.
- Selección de controles.
- Ciclo PDCA (Plan-Do-Check-Act).

## Contexto ficticio

Clínica Santa María se plantea como una institución de salud de tamaño medio, que maneja información especialmente sensible: historias clínicas, diagnósticos y datos personales de pacientes.

## Enfoque metodológico

1. Definición del alcance del SGSI.
2. Identificación de activos (tabla anterior).
3. Identificación de amenazas y vulnerabilidades asociadas a cada activo.
4. Evaluación de riesgos (probabilidad × impacto) según CIA.
5. Selección de controles con base en ISO/IEC 27001 (Anexo A) e ISO/IEC 27002.
6. Plan de tratamiento de riesgos.
7. Aplicación del ciclo PDCA para la mejora continua del SGSI.

## Aclaración

Todos los activos, riesgos y controles descritos en este caso son **hipotéticos**, construidos con fines didácticos. Ningún dato corresponde a una institución de salud real ni a pacientes reales.
